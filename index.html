Tessera

Android app · open source (GPLv3) · 2026

Runs Linux desktop apps on Android as real Android apps: Debian and 2,800+ Flathub apps, each with its own window, Recents card and home-screen icon.

  • Runs Flathub apps without bubblewrap or user namespaces, which Android kernels lack, by building each app's file system itself.
  • GPU acceleration (OpenGL 4.6, Vulkan) on Snapdragon phones through a custom Mesa Turnip and Zink build.
  • Themes GTK, libadwaita, Qt and LibreOffice with the phone's Material You colors, live.
  • A touch-friendly Linux desktop mode, live per-app scaling, and per-app permissions enforced with PRoot or kernel namespaces.

SPU Archive

Document archive for a public university (SPU) · 2026

Digitizes and searches a university's personnel records, built for about 200,000 scanned files, on ordinary hardware and fully offline.

  • Web app and API in ASP.NET Core with PostgreSQL and live updates over SignalR.
  • A scanner bridge that sends documents from TWAIN scanners or watched folders straight into the archive, and a desktop backup service.
  • An offline, CPU-only pipeline that reads Central Kurdish and Arabic-Indic administrative forms: deskewing, table detection, digit classification and name matching, with checks that refuse a row rather than guess.
  • An explainer view that overlays what the pipeline saw on each page, so every result can be checked.
